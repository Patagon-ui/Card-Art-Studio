# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1e3HPgEZu3PDigCmQuGJMSIhhi65gqurj

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

# Trading Card Art Generator

A modern web application for creating professional trading card artwork using AI. Generate unique card designs with customizable attributes, or create variations while maintaining consistent style.

## Features

- 🎨 AI-powered card artwork generation
- 🔄 Create variations of existing designs
- 🎴 Support for multiple card types (Creature, Spell, Trap)
- ✨ Custom prompt input for creative control
- 🖼️ Optional card back design
- 💾 Export high-resolution images
- ✅ And more..
